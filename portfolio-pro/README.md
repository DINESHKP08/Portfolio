# Dinesh K P Portfolio (professional layout)

Open `index.html` in a browser. No build step.

- Replace `assets/avatar.svg` with your photo (update the `src` in `index.html`; `object-fit: cover` crops it to a circle).
- Colors are at the top of `styles.css` under `:root`.
- Fonts load from Google Fonts and need an internet connection.
- Deploy free on GitHub Pages, Netlify or Vercel by uploading this folder.
